# Kedar Farmhouse: static website
One-page site (HTML, CSS, JS only). Niveli, Angaon, Bhiwandi, Thane.

## Structure
index.html, css/style.css, css/responsive.css, js/main.js, assets/images/ (empty, for your photos)

## Run locally
Unzip, then double-click index.html, or use VS Code "Live Server".

## Add your images
Copy photos into assets/images using these exact names (JPG). Empty slots show a dashed box with the file name until the image exists.
- hero.jpg (full-width top banner, landscape, about 1920x1080)
- stay-1.jpg, stay-2.jpg, stay-3.jpg (stay cards, about 800x600)
- gallery-1.jpg to gallery-6.jpg (gallery, about 1000x800)
- contact.jpg (photo or map screenshot in the contact section)
To use other file names, edit the img src in index.html.
